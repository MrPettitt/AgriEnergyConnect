Farmer & Employee Portal

Connecting farmers with the people who bring their produce to market.

Employees onboard farmers, farmers list what they have grown, and anyone can browse the public marketplace. Built with ASP.NET Core 8, EF Core and SQLite, and ready to run with a single command.

Features

Three audiences, one small app

Each role gets its own dashboard, and the marketplace is open to everyone.

🧺

For everyone

A public marketplace of every farmer's current listings, no account needed.

  • Search by product name
  • Filter by category
  • Paged results and product detail pages
🌱

For farmers

Manage your own produce listings.

  • Add, edit and delete products
  • Category and unit chosen from lists
  • Ownership enforced on the server
👥

For employees

Run the platform day to day.

  • Onboard farmers in one step
  • See all farmers and remove accounts
  • Filter produce by farmer, category and dates

Validated input

Fixed category and unit lists, positive prices, and no future production dates.

Secure by default

Role-based authorization, login lockout, hidden public registration, and demo data only in Development.

Zero-setup database

EF Core migrations create a local SQLite file on first run. No database server needed.

Run it

Up and running in three commands

All you need is the .NET 8 SDK.

git clone https://github.com/MrPettitt/AgriEnergyConnect.git
cd AgriEnergyConnect
dotnet run

In the Development environment the database is created and filled with demo data on first run. Sign in with any of these accounts:

RoleEmailPassword
Employeejohn.smith@demo.comEmployee123!
Farmerjohn.doe@demo.comFarmer123!

These are demo-only accounts. They are never created outside Development.
